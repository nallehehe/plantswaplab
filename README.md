växter som säljs måste ha ett fast pris mellan 50-1000 kr

begränsningar:
när ett byte mellan växter går igenom så ändras endast owner_user_id columnen till den nya ägaren - förbättra det genom att ha en lista hos varje user som håller i alla växter de köpt och bytt
